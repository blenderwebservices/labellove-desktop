# Reporte de Entrega: Soporte Universal de Códigos de Barras y QR (39 Simbologías de Label Live)

**Fecha y Hora:** 2026-09-24 11:30  
**Proyecto:** LabelLove Desktop Web  
**Objetivo:** Agregar soporte en LabelLove para todas las simbologías de códigos de barras y códigos 2D de las imágenes de referencia de Label Live (39 en total), con especial prioridad en la familia de códigos QR.

---

## 1. Resumen de Cambios Implementados

### 1.1 Motor Universal de Simbologías (`bwip-js` integrado localmente)
- Se incorporó la biblioteca estándar industrial **`bwip-js`** (`js/vendor/bwip-js-min.js`) para garantizar ejecución **100% offline** en entornos locales y de escritorio, con fallback automático a CDN si fuera necesario.
- El motor es capaz de renderizar con precisión sub-pixel en `<canvas>` y vectores tanto códigos 1D como 2D matriciales y apilados.

### 1.2 Catálogo Completo de 39 Simbologías de Label Live

A continuación se detalla la cobertura completa implementada y agrupada:

#### A. Familia Códigos QR (2D) — Máxima Prioridad
1. **QR Code** (`qrcode`): Estándar mundial ISO/IEC 18004 para enlaces, texto y datos generales con corrección de error configurable (L, M, Q, H).
2. **Micro QR Code** (`microqrcode`): Variante compacta de QR con un solo cuadro de esquina para piezas pequeñas e impresión de alta densidad.
3. **GS1 QR Code** (`gs1qrcode`): Estándar GS1 Digital Link con identificadores de aplicación AI entre paréntesis o FNC1.
4. **HIBC QR Code** (`hibcqrcode`): Estándar del Health Industry Bar Code para insumos médicos y hospitales.

#### B. Matrices y Códigos 2D Adicionales
5. **Data Matrix** (`datamatrix`): Matriz 2D cuadrada estándar ISO/IEC 16022.
6. **Data Matrix Rectangular** (`datamatrixrectangular`): Variante rectangular para tubos de ensayo, viales o empaques alargados.
7. **GS1 Data Matrix** (`gs1datamatrix`): Estándar obligatorio en farmacéutica y serialización de medicamentos.
8. **HIBC Data Matrix** (`hibcdatamatrix`): Data Matrix médico con sintaxis HIBC.
9. **HIBC Data Matrix Rectangular** (`hibcdatamatrixrectangular`): Variante rectangular de HIBC Data Matrix.
10. **PDF417** (`pdf417`): Código 2D apilado de alta capacidad para credenciales, licencias y logística.
11. **PDF417 - Compact** (`pdf417compact`): Versión truncada sin margen derecho para espacios angostos.
12. **PDF417 - Micro** (`micropdf417`): Variante micro de PDF417 para áreas miniaturizadas.

#### C. Retail, Comercio y Gran Consumo
13. **EAN-13** (`ean13`): Código de producto universal para comercio global.
14. **EAN-8** (`ean8`): Código de 8 dígitos para empaques pequeños.
15. **UPC-A** (`upca`): Código comercial estándar de 12 dígitos en EE.UU. y Canadá.
16. **UPC-E** (`upce`): Variante comprimida de UPC-A de 6/8 dígitos.
17. **ISBN** (`isbn`): Código para libros con validación y dígito verificador.
18. **ITF-14 / GS1-14** (`itf14`): Código con marco portador para empaques corrugados y cajas maestras.
19. **GS1-128** (`gs1-128`): Código logístico estándar con identificadores de aplicación.
20. **SSCC-18** (`sscc18`): Código serial de contenedor de envío (Serial Shipping Container Code).
21. **GS1 DataBar Omnidirectional** (`databaromni`): Código para productos frescos a granel y cupones.
22. **GS1 DataBar Stacked** (`databarstacked`): GS1 DataBar apilado en dos niveles.
23. **GS1 DataBar Expanded** (`databarexpanded`): DataBar con datos adicionales (peso, lote, caducidad).
24. **GS1 DataBar Expanded Stacked** (`databarexpandedstacked`): Variante expandida apilada multinivel.

#### D. Industriales y Logística (1D)
25. **Code 128** (`code128`): Código alfanumérico universal de alta densidad.
26. **Code 39** (`code39`): Estándar industrial y militar alfanumérico.
27. **Code 39 Extended** (`code39ext`): Soporte para los 128 caracteres ASCII completos.
28. **Code 93** (`code93`): Mayor densidad y redundancia de verificación que Code 39.
29. **Code 11** (`code11`): Código numérico de telecomunicaciones y equipos electrónicos.
30. **Codabar** (`rationalizedCodabar`): Estándar para bancos de sangre, bibliotecas y guías de mensajería.
31. **Interleaved 2 of 5 (ITF)** (`interleaved2of5`): Código numérico por pares de barras de alta densidad.
32. **MSI Modified Plessey** (`msi`): Utilizado en control de inventario y estanterías de supermercados.
33. **HIBC Code 128** (`hibccode128`): Código 128 con datos de la industria de salud.
34. **HIBC Code 39** (`hibccode39`): Código 39 con formato HIBC.

#### E. Postales y Mensajería
35. **USPS Intelligent Mail (IMb)** (`onecode`): Código postal de 4 estados para correspondencia de EE.UU.
36. **USPS POSTNET** (`postnet`): Código postal tradicional de 32 a 62 barras.
37. **Royal Mail 4 State** (`royalmail`): Código postal RM4SCC del correo británico.
38. **Royal Dutch TPG Post KIX** (`kix`): Código postal Klantindex de los Países Bajos.

## 2. Interfaz y Experiencia de Usuario

1. **Panel de Inspección (`#propBarcodeFormat`)**:
   - Organizado en grupos `<optgroup>` semánticos para facilitar la búsqueda rápida.
   - Si se selecciona un código 2D (QR, Data Matrix, PDF417), el control de *"Mostrar texto legible"* se oculta inteligentemente ya que no aplica a matrices bidimensionales.
   - Al cambiar de simbología, el sistema autocompleta con una muestra válida representativa (por ejemplo, números de 13 dígitos para EAN-13, identificadores para GS1, o URLs para QR) para evitar estados de error o formatos rotos.
2. **HUD Flotante del Lienzo (`#hudBarcodeFormat`)**:
   - Refleja y permite cambiar la simbología directamente sobre el elemento seleccionado en el lienzo.
   - Sincronizado bidireccionalmente con el Inspector.
3. **Conversión Automática de Tipo de Elemento**:
   - Si un elemento tipo `barcode` cambia a una simbología 2D (por ejemplo `qrcode` o `datamatrix`), la aplicación actualiza automáticamente `el.type = 'qr'` y adapta sus proporciones.
   - A la inversa, si un elemento tipo `qr` cambia a una simbología 1D lineal (por ejemplo `code128` o `ean13`), se ajusta a `el.type = 'barcode'`.
4. **Evaluador de Legibilidad Óptica**:
   - Se ajustó el algoritmo `evaluateReadability()` para evaluar correctamente tanto códigos 2D como 1D según resolución efectiva (DPI) y tamaño del módulo (X-dimension).

## 3. Generación ZPL II para Impresoras Térmicas Zebra

Se expandió el generador ZPL en `js/zpl-generator.js` para emitir comandos nativos de Zebra según el tipo de código:
- **QR Code**: `^BQN,2,...` (nativo QR Code Zebra)
- **Data Matrix**: `^BXN,...` (nativo Data Matrix Zebra)
- **PDF417**: `^B7N,...` (nativo PDF417 Zebra)
- **Code 128 / GS1-128**: `^BCN,...`
- **Code 39 / HIBC 39**: `^B3N,...`
- **Code 93**: `^BAN,...`
- **Code 11**: `^B1N,...`
- **EAN-13 / ISBN**: `^BEN,...`
- **EAN-8**: `^B8N,...`
- **UPC-A**: `^BUN,...`
- **UPC-E**: `^B9N,...`
- **Interleaved 2 of 5 / ITF-14**: `^BIN,...`
- **Codabar**: `^BKN,...`
- **MSI Plessey**: `^BMN,...`
- **USPS POSTNET**: `^BZN,...`
