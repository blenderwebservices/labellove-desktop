**Estado:** ✅ Implementado y Verificado  

---

## 1. Resumen Ejecutivo

Se implementó con éxito la funcionalidad de **Importación Directa de Archivos Excel (.xlsx, .xls) y CSV con soporte Multi-Hojas** en el panel lateral de datos (*Data Drawer*) de LabelLove. 

El usuario ahora puede:
1. Abrir el panel de **Datos** y hacer clic en **"Importar Excel / CSV"**.
2. Cargar cualquier libro de cálculo local sin necesidad de enviar información a un servidor externo (procesamiento 100% en el cliente mediante SheetJS).
3. Si el archivo contiene múltiples hojas, seleccionar visualmente qué hoja desea importar mediante botones interactivos ("pills") que muestran el número de filas de cada hoja.
4. Visualizar una vista previa en tiempo real de los datos, con las variables mapeadas como `{{ nombre_columna }}` debidamente normalizadas (sin tildes, minúsculas y caracteres seguros).
5. Cambiar entre hojas activas en cualquier momento directamente desde el selector de hojas integrado en la cabecera del Data Drawer, actualizando automáticamente el canvas, el inspector de campos variables, la tabla de datos y el paginador de registros.

## 2. Componentes y Modificaciones Realizadas

### 2.1. Librería de Procesamiento
- **`index.html`**: Se integró la versión minificada y optimizada de **SheetJS (`xlsx.full.min.js`)** desde CDN:
  ```html
  <script src="https://cdn.jsdelivr.net/npm/xlsx@0.18.5/dist/xlsx.full.min.js"></script>
  ```

### 2.2. Interfaz de Usuario (UI)
- **Cabecera del Data Drawer (`index.html`)**:
  - Botón principal de acción: `btnImportExcel` con icono `📊` y texto *"Importar Excel / CSV"*.
  - Selector de hoja activa: `#drawerSheetSelectorGroup` con `<select id="drawerSheetSelect">` que se muestra dinámicamente cuando el archivo cargado contiene dos o más hojas.
  - Indicador de archivo en uso: `#dataDrawerFileName` con el nombre del archivo cargado.
  - Input oculto para selección de archivos: `<input type="file" id="excelFileInput" accept=".xlsx,.xls,.csv">`.
- **Modal de Importación y Previsualización (`#excelImportModal`)**:
  - Cabecera con nombre de archivo, tamaño y conteo de hojas encontradas.
  - Botón para elegir otro archivo sin salir del flujo.
  - Selector de hojas con etiquetas tipo píldora (`.excel-sheet-pill`) con badge de conteo de filas.
  - Checkbox para activar/desactivar el uso de la primera fila como encabezado.
  - Tabla de previsualización estilizada en modo oscuro (`.excel-preview-table`) con formato de badges de variables `{{ campo }}`.
  - Banner informativo con tips de uso en el lienzo.

### 2.3. Estilos Modernos (`styles/components.css`)
- Estilos consistentes con la paleta de LabelLove (modo oscuro, acentos verde menta `rgba(16, 185, 129, ...)`, bordes redondeados y micro-transiciones).
- Scrollbars delgadas personalizadas para la tabla de previsualización.
- Estados activos y hover para las pestañas/pills de selección de hojas.

### 2.4. Capa de Datos (`js/data-store.js`)
- Soporte para estado de libro de trabajo (`workbook`, `currentFileName`, `currentSheetName`).
- Nuevos métodos:
  - `loadWorkbook(workbookData, targetSheet)`: Carga el libro completo, inicializa la hoja objetivo y preserva las demás.
  - `loadSheet(sheetName)`: Permite alternar instantáneamente de hoja sin recargar el archivo.
  - `hasMultiSheets()`: Informa si el libro actual tiene múltiples hojas.

### 2.5. Lógica de Aplicación y Eventos (`js/app.js`)
- Inicialización en `setupExcelImportEvents()`:
  - Disparador de input de archivo al pulsar *"Importar Excel / CSV"*.
  - Lectura asíncrona de archivos usando `FileReader.readAsArrayBuffer` y parsing con `XLSX.read(data, { type: 'array' })`.
  - Normalización de nombres de encabezados (`sanitizeColumnKey`) para generar nombres de variables limpios (ej. `"Código Barras"` → `"codigo_barras"`).
  - Apertura, cierre y confirmación del modal con atajo de teclado `Escape`.
  - Sincronización automática de todos los listeners al cambiar de hoja desde el drawer.

### 2.6. Archivo de Muestra para Pruebas
- Se generó el archivo de ejemplo `examples/muestras_etiquetas_multihoja.xlsx` con 3 hojas diferenciadas:
  1. **`Envios_Express`**: 7 registros de paquetería (destinatario, direccion, ciudad, cp, tracking, peso, servicio).
  2. **`Inventario_Retail`**: 6 registros de productos (sku, producto, categoria, precio, stock, ubicacion, codigo_barras).
  3. **`Gafetes_Eventos`**: 5 registros de asistentes (nombre, empresa, cargo, tipo_acceso, mesa, qr_code).

## 4. Instrucciones para Probar en el Navegador

1. Abrir `http://labellove.test` en Google Chrome u otro navegador web.
2. Hacer clic en el botón **Datos** de la barra superior derecha para abrir el *Data Drawer*.
3. En la cabecera del drawer, pulsar el botón verde **"Importar Excel / CSV"**.
4. Seleccionar el archivo de prueba ubicado en:
   ```
   examples/muestras_etiquetas_multihoja.xlsx
   ```
5. En el modal interactivo:
   - Notar las 3 hojas disponibles (`Envios_Express`, `Inventario_Retail`, `Gafetes_Eventos`).
   - Hacer clic en cada hoja para ver la actualización inmediata de la previsualización y el conteo de filas/columnas.
   - Pulsar **"Importar Datos a la Plantilla"**.
6. Observar en el Data Drawer:
   - La tabla con los nuevos datos cargados.
   - El selector de hojas en la cabecera del drawer (permite cambiar entre hojas con un solo clic).
   - El inspector y lienzo reflejan de inmediato los campos en `{{ variable }}`.
