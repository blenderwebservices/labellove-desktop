## 2. Puntos Clave Documentados

1. **Aclaración Arquitectónica (Zero-Build):**
   - Se explica explícitamente que LabelLove es una SPA cliente con ES Modules estándar sin `package.json`, por lo que **no** requiere ni debe ejecutarse `npm install` o `npm run build` en el servidor o durante el despliegue.

2. **Tres Métodos de Despliegue en Plesk:**
   - **Método 1 (Git en Plesk - Recomendado):** Configuración paso a paso de repositorio remoto, branch `main`, modo de despliegue automático/manual y la indicación clave de dejar el campo de *Acciones adicionales de despliegue* en blanco.
   - **Método 2 (Administrador de Archivos de Plesk):** Subida directa o mediante archivo `.zip` y extracción en `/httpdocs`.
   - **Método 3 (FTP / SFTP):** Carga remota directa conservando la estructura de carpetas (`index.html`, `js/`, `styles/`, etc.).

3. **Configuraciones Críticas del Servidor Web:**
   - **SSL/TLS Let's Encrypt y forzado HTTPS:** Requisito indispensable para el funcionamiento de APIs del navegador como File System Access API y Clipboard API.
   - **Procesamiento de archivos estáticos en Nginx/Apache:** Activación de *Smart static files processing* y compresión Gzip/Brotli.
   - **Independencia de PHP:** Nota aclaratoria indicando que la versión de PHP es indistinta para la aplicación.

4. **Verificación Post-Despliegue:**
   - Pasos para verificar mediante consola de desarrollador (DevTools) la ausencia de errores en carga de módulos ES y respuesta HTTP 200 en recursos estáticos.
