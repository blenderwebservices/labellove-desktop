# Reporte de Entrega: Detección y Máscaras de Formato Numérico

**Fecha y Hora:** 2026-09-24 11:40  
**Proyecto:** LabelLove Desktop Web  
**Objetivo:** Incorporar detección automática de campos numéricos y soporte universal para máscaras de formato en elementos de texto y variables reactivas (ejemplos: `12345` -> `$12,345.00`, `0.16` -> `16% IVA`, relleno de ceros `000123`, etc.).

---

## 1. Resumen de Características Implementadas

### 1.1 Motor de Formato Numérico (`js/format-engine.js`)
Se desarrolló el módulo `FormatEngine` que provee:
- **`isNumeric(val)`**: Verificación robusta de cadenas y números flotantes o enteros, tolerando comas de millares.
- **`detectNumeric(el, dataStore)`**: Inspección automática que detecta si el texto es un número directo o si está vinculado a un campo o variable reactiva (`{{ campo }}`) cuyos registros contienen valores numéricos.
  - Distingue inteligentemente entre números estándar y fracciones porcentuales (`|val| <= 1`).
  - Provee sugerencias automáticas de máscara (`0% IVA` si es fracción decimal, o `$#,##0.00` si es valor monetario/entero).
- **`applyMask(rawVal, mask)`**: Aplicador universal de máscaras basado en descomposición por patrones `[Prefijo][Patrón][Sufijo]`.
  - Escala inteligente x100 para porcentajes cuando el valor de entrada es fraccionario (`0.16` -> `16%`).
  - Redondeo y control preciso de decimales (`.00`, `.000`, `.0`).
  - Formateo de separadores de millares con coma (`,`).
  - Relleno con ceros a la izquierda (Zero-padding) mediante tokens de ceros (`00000`, `000000`).
  - Soporte de prefijos y sufijos textuales personalizados sin romper la estructura numérica.

## 3. Integración en la Interfaz de Usuario

1. **Panel de Inspección (`#sectionNumberMask`)**:
   - Aparece automáticamente al seleccionar cualquier elemento de texto.
   - Si el contenido o la variable vinculada es numérica, se activa el badge **`✓ Numérico detectado (12345)`**.
   - Menú desplegable con `<optgroup>` categorizados para fácil selección de presets.
   - Campo para máscara libre con ayuda sobre la sintaxis (`#`, `0`, `%`, etc.).
   - **Caja de Previsualización en Vivo**: Muestra al instante el resultado de la máscara calculada sobre el registro activo.
2. **Soporte de Modificadores en Plantillas / Expresiones**:
   - Además de la máscara a nivel de elemento, es posible usar filtros dentro de la expresión de la variable:
     - `{{ precio | currency }}` -> `$1,899.00`
     - `{{ tasa | percent }}` -> `16%`
     - `{{ tasa | mask:"0% IVA" }}` -> `16% IVA`
     - `{{ sku | mask:"000000" }}` -> `000123`
3. **Persistencia e Historial**:
   - Los atributos `el.mask` y `el.customMask` se guardan en el archivo `.love` del proyecto, en el auto-guardado local y en el árbol de Deshacer/Rehacer (`saveHistory()`).

---

## 4. Renderizado en Lienzo y ZPL II para Impresoras Zebra

- **`CanvasManager` (`js/canvas.js`)**: Renderiza en tiempo real los elementos de texto y códigos con la máscara aplicada, actualizándose reactivamente al navegar entre registros en el Data Drawer.
- **`ZPLGenerator` (`js/zpl-generator.js`)**: Emite el texto formateado directamente en los bloques `^FD...^FS` para garantizar que la impresión física coincida exactamente con la previsualización digital.

## 5. Pruebas y Validación Realizadas

1. **Pruebas Unitarias en Node**:
   - `12345` con `$#,##0.00` => `$12,345.00` (OK)
   - `0.16` con `0% IVA` => `16% IVA` (OK)
   - `0.16` con `0.0% IVA` => `16.0% IVA` (OK)
   - `16` con `0% IVA` => `16% IVA` (OK)
   - `123` con `000000` => `000123` (OK)
   - `12345` con `$#,##0.00 MXN` => `$12,345.00 MXN` (OK)
   - `-1234.5` con `$#,##0.00` => `-$1,234.50` (OK)
2. **Prueba de Generación ZPL**:
   - Se validaron comandos `^FD$12,345.00^FS`, `^FD16% IVA^FS` y `^FD$1,899.00 MXN^FS`.
3. **Validación Sintáctica y DOM**:
   - `node --check` validó sin errores todos los archivos JS modificados.
   - Navegación headless verificó la presencia correcta de `#sectionNumberMask` y selectores en `http://labellove.test`.
