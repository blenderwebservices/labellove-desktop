## 1. Contenido Incorporado en `README.md`

### 1.1 Intención y Visión del Proyecto
- **El Problema:** Explica las limitaciones del ecosistema de software de etiquetas heredado (*ZebraDesigner*, *BarTender*), tales como la atadura a Windows, interfaces arcaicas, costos elevados de licencias y la desconexión entre la impresión térmica de rollo y la impresión en pliegos de hoja suelta.
- **La Solución:** Posiciona a LabelLove como una estación de trabajo moderna, ligera, orientada a la web (Zero-build, ES Modules puros), con precisión milimétrica física, doble motor de impresión y enlaces de datos reactivos.

### 1.2 Características Principales
- **Lienzo Interactivo WYSIWYG:** Precisión física en milímetros, transformer de 8 tiradores con rotación angular, guías magnéticas de centrado y bordes, reglas milimétricas y redimensionamiento dinámico del escenario.
- **Motor Universal de Códigos de Barras y 2D (`BarcodeEngine`):** Catálogo de más de 39 simbologías (QR, Micro QR, GS1 QR, HIBC, Data Matrix, PDF417, EAN-13, Code 128, etc.) procesadas con `bwip-js`.
- **Impresión Térmica en Rollo Continuo (ZPL II):** Generación de código nativo para impresoras Zebra, TSC y Rollo en 203, 300 y 600 DPI.
- **Impresión en Hoja / Matriz (Carta, A4, Avery):** Motor matricial (`SheetPrintEngine`) con presets (5×18 = 90 etiquetas, Avery 5160, 5163, 5164, etc.), salto de celdas iniciales (offset) y soporte nativo del diálogo del sistema vía `@media print`.
- **Motor de Datos y Variables Reactivas:** Interpolación `{{variable}}`, formateador numérico/divisas (`FormatEngine`) e importación de archivos Excel (`.xlsx`, `.xls`) y `.csv` con `SheetJS`.
- **Gestión Documental y Persistencia:** Formato abierto `.labellove`, autoguardado en `localStorage`, integración con la File System Access API y apertura por Drag & Drop.

### 1.3 Arquitectura Técnica
- **Diagrama de Bloques / Capas:** Esquema que visualiza la separación entre la Capa de Presentación (UI), el Orquestador Central (`App`), los Motores de Negocio (`CanvasEngine`, `BarcodeEngine`, `SheetPrintEngine`, `ZPLGenerator`, `DocumentManager`), y la Capa de Estado (`DataStore`, `FormatEngine`, `Templates`).
- **Tabla de Módulos:** Detalle técnico de responsabilidades por archivo fuente en `js/`.
- **Sistema de Diseño y Tokens CSS:** Desglose de responsabilidades de `theme.css`, `canvas.css` y `components.css`.

### 1.4 Especificación y Guías de Uso
- **Esquema de Archivo `.labellove`:** Estructura JSON canónica documentada.
- **Puesta en Marcha:** Guías para ejecutar con Laravel Herd, Python `http.server`, Node/npx y Live Server.
- **Atajos de Teclado:** Tabla de atajos (`Cmd+P`, `Cmd+S`, `Cmd+Z`, `Espacio + Arrastre`, etc.).
- **Árbol de Directorios del Repositorio:** Mapa completo de carpetas y archivos.
