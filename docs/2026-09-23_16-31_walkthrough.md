     `225bfe1 chore: add .gitignore file`.

2. **Diagnóstico del Error de Autenticación en `git push`:**
   ```text
   remote: Invalid username or token. Password authentication is not supported for Git operations.
   fatal: Authentication failed for 'https://github.com/blenderwebservices/labellove.git/'
   ```
   Se identificaron las dos causas exactas que provocan este error:
   - **Causa A**: El repositorio aún no existe en GitHub bajo `blenderwebservices/labellove` (retorna `404 Not Found`). GitHub solicita credenciales y las rechaza cuando el destino no existe.
   - **Causa B**: GitHub no acepta contraseñas convencionales por HTTPS desde 2021; requiere un **Personal Access Token (PAT)** o vinculación por SSH / GitHub CLI. Además, el llavero de macOS (`osxkeychain`) puede tener almacenado un token previo o inválido.

## 🚀 Guía de Solución Paso a Paso

### Paso 1: Crear el repositorio en GitHub
1. Ingresa a [github.com/new](https://github.com/new).
2. Asegúrate de seleccionar el propietario correcto (`blenderwebservices` o tu usuario personal).
3. Nombre del repositorio: `labellove`.
4. Selecciónalo como Público o Privado.
5. **No** marques la opción de inicializar con README, `.gitignore` ni Licencia (ya los tenemos listos localmente).
6. Haz clic en **Create repository**.

### Paso 2: Generar un Personal Access Token (PAT) en GitHub
Si GitHub te pide autenticación por HTTPS:
1. Ve a [github.com/settings/tokens](https://github.com/settings/tokens) (o Settings > Developer Settings > Personal access tokens > Tokens (classic)).
2. Haz clic en **Generate new token (classic)**.
3. Asigna un nombre (ej. `MacBook Pro`) y marca la casilla **`repo`** (acceso completo a repositorios).
4. Genera el token y cópialo.

### Paso 3: Limpiar credenciales previas y publicar
1. Si macOS tiene una credencial vieja en caché, puedes borrarla ejecutando:
   ```bash
   printf "protocol=https\nhost=github.com\n" | git credential-osxkeychain erase
   ```
2. Realiza el push:
   ```bash
   git push -u origin main
   ```
3. Cuando te pida:
   - **Username**: tu usuario de GitHub o email (`blender.webservices@gmail.com`).
   - **Password**: pega el **Personal Access Token (PAT)** que generaste en el Paso 2 (NO tu contraseña normal de GitHub).
