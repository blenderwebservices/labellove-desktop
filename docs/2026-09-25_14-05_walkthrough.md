# Walkthrough: Validación Diferida de Dimensiones del Lienzo

Se resolvió el problema donde el control de dimensiones del lienzo validaba inmediatamente y forzaba el valor mínimo de `15` al intentar teclear cualquier número que empezara con `1` (ej. `100`, `15`, `120`), tanto para ancho como para alto.

---

## Causa Raíz del Problema

1. Los campos `#labelWidthMm` y `#labelHeightMm` tenían registrado un listener para el evento `'input'`, ejecutándose en cada pulsación de tecla.
2. Al escribir `1`, la función ejecutaba de inmediato `canvasEngine.setCanvasSize(1, h)`.
3. `setCanvasSize` aplicaba `Math.max(15, ...)`, forzando el valor a `15`.
4. Seguidamente, se emitía `onCanvasResize`, que llamaba a `updateInspectorLabelSettings()`, y esta función sobreescribía el valor del input activo con `wInput.value = 15`.
5. Esto reemplazaba el texto que el usuario estaba escribiendo antes de que pudiera completar el número deseado.

---

## Cambios Implementados

### 1. Validación Diferida al Confirmar (`commitDimensionChange`) ([js/app.js](file:///Users/francisco/Herd/labellove/js/app.js))
- **Eliminación del listener `input` destructivo**: El usuario ahora puede teclear libremente cualquier cifra (por ejemplo, teclear `1`, luego `0`, luego `0` para obtener `100`) sin que el campo sea alterado mientras escribe.
- **Validación al confirmar**: La validación y el redimensionamiento del lienzo ahora se ejecutan únicamente cuando:
  - El usuario sale del campo o cambia el foco (`change` y `blur`).
  - El usuario presiona la tecla `Enter`.
- **Cancelación con `Escape`**: Si el usuario presiona la tecla `Escape`, se restaura el valor previo del lienzo y se desenfoca el campo.
- **Límites con retroalimentación clara (`showToast`)**:
  - Si el usuario introduce un número menor a `15 mm`, se ajusta a `15 mm` y se notifica con un toast de advertencia: *"El ancho/alto mínimo permitido es 15 mm"*.
  - Si el usuario introduce un número mayor a `600 mm`, se ajusta a `600 mm` y se notifica con un toast: *"El ancho/alto máximo permitido es 600 mm"*.
  - Si el campo se deja vacío o contiene caracteres inválidos, se restituye limpiamente la medida previa.

### 2. Protección de Campos con Foco Activo ([js/app.js](file:///Users/francisco/Herd/labellove/js/app.js))
- En `updateInspectorLabelSettings()`:
  ```javascript
  if (wInput && document.activeElement !== wInput) wInput.value = t.widthMm;
  if (hInput && document.activeElement !== hInput) hInput.value = t.heightMm;
  ```
  Esto garantiza que ninguna actualización externa sobreescriba lo que el usuario está escribiendo en el campo activo.

### 3. Integración con el Botón de la Barra Superior (`#canvasDimBadge`) ([js/app.js](file:///Users/francisco/Herd/labellove/js/app.js))
- Al hacer clic en el botón `📐 ... mm` de la barra superior:
  - Se activa la pestaña "Etiqueta" del inspector.
  - Se enfoca automáticamente el campo `#labelWidthMm` y se selecciona su texto (`select()`), permitiendo al usuario empezar a teclear la nueva dimensión de inmediato.

### 4. Ajuste de Atributos HTML ([index.html](file:///Users/francisco/Herd/labellove/index.html))
- Se actualizó el atributo `max="600"` en ambos campos para reflejar la capacidad máxima real soportada por el motor del lienzo.
