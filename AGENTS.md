# Reglas de Trabajo para LabelLove

## Registro de Documentación y Planes

Para cualquier trabajo, desarrollo o sesión en este proyecto:

1. **Planes de Implementación (`Implementation Plan`)**:
   - Cada vez que se elabore un plan de implementación, además del artefacto interno, debe guardarse en la carpeta `docs/` del proyecto con una marca de fecha y hora.
   - Formato de nomenclatura: `docs/YYYY-MM-DD_HH-mm_implementation_plan.md`.

2. **Reportes de Entrega (`Walkthrough`)**:
   - Al concluir las tareas o cambios al final de cada chat o ciclo de trabajo, guardar el documento de walkthrough en la carpeta `docs/` con su respectiva marca de fecha y hora.
   - Formato de nomenclatura: `docs/YYYY-MM-DD_HH-mm_walkthrough.md`.

3. **Notas y Scratchpads (si aplica)**:
   - Cualquier archivo de checklist o scratchpad relevante debe resguardarse en `docs/` siguiendo el mismo formato de timestamp: `docs/YYYY-MM-DD_HH-mm_scratchpad.md`.
